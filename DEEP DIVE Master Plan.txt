DEEP DIVE

Master Game Design & Development Specification

Version 2.0 — Sea Expansion & Dynamic Biomes

---

0. PROJECT IDENTITY

Game Name

DEEP DIVE

Genre

Roblox:

- Exploration
- Fishing / Deep-Sea Discovery
- RNG
- Collection
- Progression
- Equipment
- Trading
- Limited-time world events

Core Fantasy

The player enters an increasingly mysterious ocean and searches for things that should not be there.

You begin by finding:

«Tin Cans
Bottles
Old Coins
Broken Equipment»

Eventually:

«Ancient Artifacts
Leviathan Scales
Void Crystals
Astral Objects
Reality Fragments
Glitched Objects»

The central fantasy is:

«"What will I find if I go deeper?"»

And the secondary fantasy is:

«"What will my item become if something strange happens to the ocean?"»

---

1. DESIGN PILLARS

Deep Dive is built around five pillars.

1.1 Discovery

The player should constantly wonder:

«"What's down there?"»

Unknown items, deeper Seas, rare variants, secret events and bizarre biomes should continuously create curiosity.

1.2 RNG With Meaning

RNG is not simply a slot machine.

The player should improve their odds through:

- Equipment
- Sea progression
- Upgrades
- Player decisions
- Event participation
- Collection progression

Luck should influence outcomes, but progression should never feel completely irrelevant.

1.3 Depth

Going deeper must feel meaningful.

Every new Sea should introduce:

- New items
- Higher rarity
- New mechanics
- Better equipment
- New visual identity
- New event possibilities

1.4 Collection

Every discovery should contribute toward a larger collection.

Players should eventually chase:

- Every base item
- Every rarity
- Every biome variant
- Every exclusive item
- Every equipment piece

1.5 Surprise

Deep Dive should be willing to become increasingly ridiculous.

The game begins relatively grounded.

Eventually the ocean can become:

«Crimson.»

Then:

«Frozen.»

Then:

«Void.»

Then:

«Galactic.»

Then:

«Glitched.»

Then:

«Something that clearly should not exist.»

The escalation is part of the game's identity.

---

2. CORE GAME LOOP

The fundamental loop is:

ENTER SEA
    ↓
DIVE / FISH / SEARCH
    ↓
DISCOVER OBJECT
    ↓
RNG DETERMINES RESULT
    ↓
RARITY DETERMINED
    ↓
ACTIVE BIOME MODIFIER CHECKED
    ↓
PREFIX / VARIANT APPLIED
    ↓
ITEM ADDED TO INVENTORY
    ↓
SELL / KEEP / TRADE
    ↓
BUY EQUIPMENT / UPGRADE
    ↓
UNLOCK DEEPER SEA
    ↓
DISCOVER RARER ITEMS
    ↓
REPEAT

The player should understand the basic loop within approximately one minute.

3. CYCLE

Discovery → Collection → Equipment → Sea Progression → Biome Hunting

This keeps the game focused on exploration and discovery rather than introducing a separate maintenance mechanic.

6. EQUIPMENT SYSTEM

Equipment replaces Restoration as the major permanent progression system.

Five equipment categories exist:

1. Pickaxe / Primary Tool
2. Bracelet
3. Hood
4. Hat
5. Mantle

Each category should scale alongside the Sea.

---

7. EQUIPMENT POWER

Every piece has:

Power

Determines progression toward deeper Seas.

Luck

Improves RNG outcomes.

Discovery

Improves chances of finding higher-tier objects.

Variant Chance

Improves chances of receiving biome-modified objects.

Value

Improves economic output where appropriate.

Not every equipment item needs every stat.

10. EQUIPMENT UPGRADES

Each equipment piece can be upgraded.

Upgrade categories:

Power Upgrade

Luck Upgrade

Improves RNG.

Improves high-rarity discovery.

Variant Upgrade

Improves biome variant chances.

Value Upgrade

Increases item selling value.

The player should gradually invest into equipment instead of replacing everything every few minutes.

11. ITEM SYSTEM

Deep Dive uses Base Items + Rarity + Variant.

The game should NOT create a completely separate database entry for every combination.

Example:

Base Item:
Tin Can

Rarity:
Common

Biome Prefix:
Crimson

Display:

«Crimson Tin Can»

This system allows thousands of combinations without thousands of manually defined objects.

15. DYNAMIC BIOME EVENTS

This is a major Deep Dive system.

Every 30 minutes, the server rolls a temporary biome event.

Example:

00:00 — Normal
00:30 — Event
01:00 — Normal
01:30 — Event
02:00 — Normal

Event duration:

10–15 minutes

Recommended initial value:

12 minutes

Then the server returns to normal conditions.

---

36. TRADING

Trading should be considered a core long-term feature.

Players can trade:

- Items
- Variant items
- Equipment
- Potentially event-exclusive items

Trading should be server-authoritative.

Every trade requires:

1. Player A selects items.
2. Player B selects items.
3. Both confirm.
4. Confirmation locks the trade.
5. Both confirm again.
6. Server executes transaction atomically.

Never trust the client with item ownership.

---

37. TRADE VALUE

Items should have:

- Base value
- Rarity
- Variant
- Event source
- Discovery rarity

The displayed shop value is NOT necessarily the same as player-to-player market value.

This is intentional.

Rare variants should develop their own player-driven value.

39. F2P DESIGN

Deep Dive must remain fully playable without spending Robux.

Premium should provide:

- Cosmetics
- Convenience
- Extra customization
- Visual effects
- Optional inventory convenience
- Private servers
- Cosmetic titles

Premium should NOT:

- Lock Seas
- Lock exclusive progression
- Guarantee Mythic items
- Guarantee Secrets
- Make F2P players objectively unable to compete

Potential products:

- Cosmetic customization
- Extra cosmetic slots

47. LUCK SYSTEM

Luck should be mathematically controlled.

Luck should modify probability rather than directly guaranteeing results.

Conceptually:

FinalLuck =
BaseLuck
+
EquipmentLuck
+
TemporaryBuffs
+
BiomeBonus

Then use a server-side RNG system.

Luck must have diminishing returns.

This prevents players from eventually reaching:

«"Nothing below Mythic exists."»

48. DISCOVERY POWER

Discovery Power determines access to deeper content.

+

Total Power

53. ANTI-EXPLOIT

Validate every remote request.

Example:

Client says:

«"I found a Mythic Pearl."»

Server response:

«"Did the server actually generate that item?"»

If not:

«Reject.»

Never accept client-provided:

- Item values
- Currency amounts
- Rarity
- Equipment stats
- Sea level
- Trade contents

76. CORE BALANCE RULE

The player should always have three visible goals:

Immediate

«"I want to find something rare."»

Medium-term

«"I want this upgrade."»

Long-term

«"I want to reach the next Sea."»

The game becomes unhealthy if all progression is reduced to:

«"Grind money."»

---

77. THE MOST IMPORTANT RETENTION MECHANIC

The 30-minute biome cycle creates a natural recurring question:

«"What's happening to the ocean next?"»

The player may log in normally and discover:

«🌊 CRIMSON WATERS»

Then later:

«☄️ GALACTIC STORM»

Then eventually:

«⚠️ SYSTEM ERROR»

This should make Deep Dive feel like a world rather than a static RNG simulator.

79. NON-NEGOTIABLE RULES

1. Restoration is removed permanently.
2. The Sea is the main progression system.
3. Equipment must scale with Sea progression.
4. There must be at least 20 temporary biomes at 1.0.
5. Biomes occur on a 30-minute cycle.
6. Biomes modify discovered items through prefixes/variants.
7. The base item and variant must be separate data concepts.
8. The system must support future multi-prefix variants.
9. There must be at least 50 base items at 1.0.
10. F2P players must be able to reach the complete progression.
11. Premium content is primarily convenience/cosmetic.
12. RNG is server-authoritative.
13. Trading is server-authoritative.
14. Player data is server-authoritative.
15. The Index tracks base items AND variants.
16. Rare events must feel substantially different from normal gameplay.
17. Late-game content should become increasingly surreal.
18. New content must be addable without rewriting core systems.
19. No single equipment category should become irrelevant.
20. The game must remain understandable despite increasing complexity.

81. DEVELOPMENT NORTH STAR

When deciding whether a feature belongs in Deep Dive, ask:

«Does this make discovering, collecting, upgrading, going deeper, or hunting something rare more exciting?»

If yes:

Build it.

If no:

Question why it exists.

Deep Dive should remain focused on one fantasy:

GO DEEPER. FIND SOMETHING IMPOSSIBLE.
